# YouTube Command Center PRO — Android launcher

This Android package opens the live dashboard in a Chrome Custom Tab. This intentionally uses the user's browser for Google OAuth rather than embedding Google's sign-in page inside a WebView, which can be blocked by Google.

Dashboard: https://youtube-command-center-pro-production.up.railway.app/

The APK requires internet access and a supported browser. It does not bundle the backend or make server-side YouTube features available if the website/backend is down.
